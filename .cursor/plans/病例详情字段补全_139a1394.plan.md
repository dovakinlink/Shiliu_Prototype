# 病例详情页字段补全计划

## 现状分析

当前 `CaseDetail` 模型仅包含基础字段（性别、出生年、确诊日期、疾病状态、转移部位、共病、预警），以及通用的 `StructuredField` 列表。对照数据字典 ([doc/Shiliu_Data_Dictionary.xlsx](doc/Shiliu_Data_Dictionary.xlsx)) 中定义的 L2 层 **17 个实体**，以下关键临床信息在详情页**完全缺失**：

- **诊断与分期**：ICD-10、分期体系(AJCC版本)、TNM 细分(T/N/M)、病理诊断结论
- **分子检测与标志物**：基因检测结果(EGFR/ALK/KRAS 等)、生物标志物(PD-L1/MSI/HER2/TMB)、样本类型
- **治疗用药详情**：方案类型、具体药物通用名、药物类别、用药起止日期、剂量调整、停药原因
- **检验结果**：肝功(ALT/AST/TBil)、肾功(Cr/eGFR)、血常规(WBC/ANC/HGB/PLT)、异常标记、CTCAE分级
- **影像与疗效**：影像类型、影像印象、RECIST 疗效评价(CR/PR/SD/PD)
- **不良事件**：AE术语、分级、起始日期、归因
- **体征与感染**：体重、乙肝状态(HBV)
- **就诊记录**：就诊类型、入院/出院日期

## 设计原则

- 手机端单页滚动 + **可折叠信息板块**，医生可快速定位关注区域
- 每个板块用 `InfoCard` + 折叠头部，默认展开前3个关键板块
- 数据全部来自 mock，无需后端 API
- 保持现有时间线/结构化字段/证据定位功能不变

## 改动范围

### 1. 扩展数据模型 ([lib/features/case_detail/domain/case_models.dart](lib/features/case_detail/domain/case_models.dart))

新增以下类型：

```dart
// 诊断与分期
class DiagnosisInfo { primarySiteCode, icd10Code, pathologyDiagnosis, stageSystem, tnmT, tnmN, tnmM, ajccStage }

// 分子检测结果（一条基因一条记录）
class MolecularResult { gene, variant, status(POS/NEG/NOT_TESTED), sampleType }

// 生物标志物
class BiomarkerResult { name, value }

// 治疗线 + 具体药物
class TreatmentLine { lineNo, regimenName, regimenType, drugs(List<DrugExposure>), startDate, endDate }
class DrugExposure { drugGeneric, drugClass, startDate, endDate }

// 检验批次 + 结果项
class LabPanel { collectionDate, results(List<LabResult>) }
class LabResult { testName, value, unit, refLow, refHigh, isAbnormal, ctcaeGrade }

// 影像 + 疗效
class ImagingRecord { studyType, date, impression, response }

// 不良事件
class AdverseEventRecord { aeTerm, grade, startDate, attribution }

// 体征与感染
class VitalSignsInfo { ecog, weight }
class InfectionInfo { hbvStatus }
```

在 `CaseDetail` 中添加这些字段：

```dart
class CaseDetail {
  // ... existing fields
  final DiagnosisInfo diagnosis;
  final List<MolecularResult> molecularResults;
  final List<BiomarkerResult> biomarkers;
  final List<TreatmentLine> treatmentLines;
  final List<LabPanel> labPanels;
  final List<ImagingRecord> imagingRecords;
  final List<AdverseEventRecord> adverseEvents;
  final VitalSignsInfo vitalSigns;
  final InfectionInfo? infectionStatus;
}
```

### 2. 补充 mock 数据 ([lib/data/mock/mock_seed_data.dart](lib/data/mock/mock_seed_data.dart))

为 24 个种子病例生成符合临床实际的 mock 数据：
- 基于瘤种差异化生成分子检测（如肺癌 EGFR/ALK，胃癌 HER2/MSI）
- 肝功/血常规等检验按肝功异常标记区分正常/异常值
- 治疗线数与已有 `lineOfTherapy` 对齐
- 不良事件与已有 `alerts` 逻辑关联

### 3. 重构病例详情页 UI ([lib/features/case_detail/presentation/case_detail_page.dart](lib/features/case_detail/presentation/case_detail_page.dart))

将现有 `_OverviewCard` 替换为 **8 个可折叠信息板块**：

| 板块 | 图标 | 展示字段 | 默认状态 |
|------|------|----------|---------|
| 病例概览 | article | 性别/出生年、确诊日期、疾病状态、转移部位、共病、预警 | 展开 |
| 诊断与分期 | biotech | 原发部位编码、ICD-10、病理诊断、分期体系、T/N/M、AJCC分期 | 展开 |
| 分子检测 | science | 基因检测列表(基因+变异+状态)、生物标志物列表 | 展开 |
| 治疗用药 | medication | 各治疗线(方案名+类型+药物明细+日期) | 折叠 |
| 检验结果 | lab_profile | 按类别分组(肝功/肾功/血常规)、异常高亮、CTCAE分级 | 折叠 |
| 影像与疗效 | radiology | 影像类型+印象、RECIST评价 | 折叠 |
| 不良事件 | warning | AE列表(术语+分级+日期+归因) | 折叠 |
| 体征与感染 | monitor_heart | ECOG、体重、HBV状态 | 折叠 |

### 4. 新增可折叠板块组件 ([lib/shared/widgets/](lib/shared/widgets/))

新建 `collapsible_section.dart`：带展开/折叠动画的通用信息板块组件，供详情页各区块复用。

### 5. 更新 mock 仓库与 store ([lib/data/mock/mock_app_store.dart](lib/data/mock/mock_app_store.dart))

`createCase` 方法需为新建病例生成默认空值的新字段。
